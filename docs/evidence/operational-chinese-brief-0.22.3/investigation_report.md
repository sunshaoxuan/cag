# 分诊失败中文摘要补强报告

日期：2026-07-31

版本：0.22.3

## 发现

0.22.2 对 `OI-10CE919F81` 执行真实重新规划时，调查命令输出超过运行时
分块限制，返回：

```text
ValueError: Separator is not found, and chunk exceed the limit
```

队列失败处理只更新了问题状态和原始错误，没有替换旧决策摘要、实施方式说明
和管理员操作。前端可以显示中文占位文案，后端记录仍可能保留上一版英文内容。

## 修正

1. 分诊运行时失败后生成 `administrator_language: zh-CN` 决策摘要。
2. 中文记录包含问题归纳、影响、根因说明、改进目标、建议改进点、验收、
   回滚、管理员操作和阻断项。
3. 原始技术错误保留在中文根因说明和审计事件中。
4. 实施方式重置为 `undetermined`，审批状态保持关闭。
5. 上一版决策继续保留在版本化 artifact，不作为本轮审核依据。
