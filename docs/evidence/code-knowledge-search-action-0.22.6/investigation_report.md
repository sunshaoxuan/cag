# 0.22.6 代码事实搜索按钮排版调查

## 结论

代码事实浏览器的“检索事实”按钮下沉来自搜索表单的网格对齐和全局标签间距叠加：按钮原本为 44px 高，输入框和下拉框为 50px 高；表单使用底部对齐，搜索标签还继承了全局 9px 下边距。

## 修正

`frontend/src/styles.css` 对 `.code-search button` 使用 50px 最小高度，并将 `.code-search label` 的下边距设为 0。按钮现在与项目、搜索和类型控件共享相同的顶部和底部坐标。760px 以下的单列布局仍将按钮作为独立行展示。

| Claim | Evidence | Confidence | Limitation |
|---|---|---|---|
| 原按钮与控件垂直错位 | 浏览器初始测量：按钮 `y=695`、控件 `y=680`，按钮高 44px、控件高 50px | high | 使用当前本机 1280px 视口 |
| 桌面修正有效 | 最终测量：按钮和三个控件均为 `y=680`、`bottom=730`、`height=50` | high | 浏览器验证针对本地 5173 页面 |

| 页面无浏览器告警 | 最终浏览器日志为 `[]` | high | 仅覆盖本次加载期间 |
