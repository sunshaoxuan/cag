# 中文问题归纳调查报告

日期：2026-07-31

版本：0.22.1

## 问题

0.22.0 已经把审核摘要与完整日志分离。真实运行中的规划和 Review
提示词、developer instruction 和结构化字段仍以英文描述为主，因此
`OI-6B26534BF5` 的问题归纳、影响、根因、改进点和阻断项生成了英文内容。

## 修正

0.22.1 增加以下约束：

1. `OperationalPlan` 与 `OperationalReview` 必须声明
   `administrator_language: zh-CN`。
2. 提示词和只读运行指令明确要求所有管理员审核文本使用简体中文。
3. 主要规划字段、改进项和 Review 阻断项必须包含中文内容。
4. 代码标识、命令、路径、API 名称、错误码和必要的错误原文保持原样。
5. 语言校验失败时进入 `plan_revision_required`，主视图使用中文失败归纳，
   原始输出只保留在折叠证据中。
6. 管理员操作要求和边界回退说明改为中文。

## 范围

语言门禁作用于新执行的规划和独立 Review。历史版本化证据继续保持原文。
活动问题可以通过“重新规划与 Review”生成新的中文版本，并与旧版本并存。
